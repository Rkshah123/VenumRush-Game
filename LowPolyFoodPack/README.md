# Low Poly Food Pack (Free)
by reodesuxz

30 cute low poly food models: fruit and veg, bakery and sweets, meals and drinks.

## Contents
- FBX/  - one .fbx per model (Unity, Unreal, Godot, Blender)
- GLB/  - one .glb per model (Godot, three.js, Babylon.js, web)
- OBJ/  - one .obj + .mtl per model
- Food_AllAssets.blend - every model in one Blender file (Blender 4.3+)

## Specs
- Total: 5674 triangles for all 30 models (32-528 tris each)
- Flat-shaded, coloured with simple shared materials (no textures needed)
- Real-world scale in metres (an apple is about 9 cm), pivot at the base centre
